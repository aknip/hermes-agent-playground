# 03 — Hermes Agent Software Company

**ESF — Enterprise Software Factory**: Konzept für eine autonom agierende
Organisation aus Hermes-Agenten, die eine bestehende B2B-Software kontinuierlich
weiterentwickelt: Markt- und Wettbewerbsanalyse, lebende Feature-Roadmap,
Sprints und Releases, Qualitätssicherung, Aufwandsschätzung mit
Ist-Kalibrierung — mit einem Menschen in der CEO-Rolle, der nur an definierten
Gates entscheidet.

- **[`KONZEPT.html`](KONZEPT.html)** — das vollständige Konzept, im Browser
  öffnen. Enthält Rechercheteil (vergleichbare Projekte, Best Practices,
  Failure Modes), Organisationsmodell, Board-Design, Gate-Mechanik,
  browserbasierte E2E-Suite (Playwright) als Regressionsnetz und lebendes
  Nutzerhandbuch, Superpowers-Skills als Bau-Methodik, OpenRouter als
  LLM-Provider mit Kosten-Tracking je Rolle, Hermes-nativen Betrieb
  (Cron-Tick, Monitor- und Report-Skripte), Umsetzungs-Roadmap und
  Verifikationsstatus.

Erstellt am 17.08.2026. Alle Hermes-Aussagen sind gegen die verifizierten
Tutorials in `02-hermes-agent-kanban-tutorials/` (v0.20.0) geprüft;
Annahmen sind im Dokument als solche markiert.
