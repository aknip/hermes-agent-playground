Spezifikation: docs/ESF-PROBELAUF.md

Karte t_c6c2f9d7 · Probelauf 1/4 (Mechanik-Test der Kette Spezifikation → Bau → Review → Riegel)

1. Problem und Zweck

Dieses Feature ist kein Produkt-Nutzen, sondern ein Organisations-Mechanik-Test: Es prüft, ob die Übergabe Spezifikation → Bau → Review → Riegel trägt. Das Ergebnis ist eine winzige, risikofreie, überprüfbare Änderung am Produkt-Repo.

2. Gewünschtes Ergebnis (Verhalten)

Das Produkt-Repo — das Repo, das in den Bau- und Riegel-Schritten verändert wird — enthält eine neue Datei docs/ESF-PROBELAUF.md mit genau drei Zeilen, in dieser Reihenfolge:

  1. eine Überschrift (beliebiger Text, der die Datei als Probelauf-Nachweis kennzeichnet),
  2. das heutige Datum,
  3. der Satz Diese Datei belegt, dass die ESF-Kette Spezifikation → Bau → Review → Riegel durchgelaufen ist.

Weder Inhalt noch Länge der drei Zeilen ändern den Zweck der Karte; es zählt die Form: genau drei Zeilen, kein zusätzlicher Inhalt.

3. Grenzen

  • Die Änderung berührt ausschließlich die neue Doku-Datei docs/ESF-PROBELAUF.md. Kein bestehender Code, keine Konfiguration, keine bestehende Datei wird verändert.
  • Es entsteht keine eigene E2E-Journey für diese Doku-Datei — eine Doku-Datei hat kein nutzbares Verhalten, das eine Journey abbilden könnte.
  • Es entsteht kein Rückbau- oder Migrationspfad: Die Datei ist ein statischer Nachweis, den keine Nutzer-Rolle konsumiert.

4. Akzeptanzkriterien

  • docs/ESF-PROBELAUF.md existiert im Produkt-Repo und hat genau drei Zeilen: Überschrift, heutiges Datum, der Probelauf-Satz.
  • Die Datei docs/ESF-PROBELAUF.md beginnt mit einer Überschrift (Zeile 1), trägt das Datum des Bautags (Zeile 2) und endet mit dem Satz Diese Datei belegt, dass die ESF-Kette Spezifikation → Bau → Review → Riegel durchgelaufen ist. (Zeile 3).
  • E2E-Szenario: Die vorhandene E2E-Suite des Produkts läuft nach Einbau der Doku-Datei weiterhin grün — kein bestehender E2E-Test fällt, keine Journey ändert sich. (Diese Doku-Datei bekommt keine eigene Journey.)
  • Keine andere Datei im Produkt-Repo wird durch diese Karte verändert.
Hinweis an den Bau: Der Satz in Zeile 3 muss den Pfeil → (U+2192) enthalten, wie in dieser Spezifikation geschrieben.
