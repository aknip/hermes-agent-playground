# ESF — Markt-Quellen des Ziel-Produkts (Kaneo, Projektmanagement/Kanban)
#
# Format:  <dateiname> | <url>
# Zeilen mit # sind Kommentare.
#
# tick.sh holt diese Quellen täglich per curl nach
# company/sources/<datum>/<dateiname>. Der esf-market-scout liest
# ausschliesslich dieses Verzeichnis — Worker haben keinen Webzugriff.
#
# Eine Quelle, die nicht antwortet, hinterlässt eine <dateiname>.fehler-Datei.
# Das ist Absicht: Ein stillschweigend fehlender Tag macht den Korpus zur Lüge.
#
# Auswahl: direkte Wettbewerber von Kaneo (einfache, oft selbst-gehostete
# Kanban-/Projektplanung) plus die zwei Kategorieführer, an denen der
# Erwartungshorizont der Käufer hängt.
